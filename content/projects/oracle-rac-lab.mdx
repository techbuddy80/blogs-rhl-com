## Overview

A two-node Oracle RAC cluster running on Proxmox, built to validate
failover and Cache Fusion behavior in a controlled environment before
recommending changes professionally.

## Lessons learned

Interconnect latency dominates every performance conversation long before
storage throughput becomes the bottleneck.

## Future improvements

Add a third node and script automated failover testing.
